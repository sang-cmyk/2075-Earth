# 수업 전 점검표 (선생님용)

점검 모드를 쓰기 전에 학생 기기로 직접 눌러 보는 항목과, 점검 모드에서 자동으로 보는 항목으로 나눴다. 체크 칸은 복사해서 쓰면 된다.

## A. 점검 모드로 먼저 (혼자서, 5분)
- [ ] 테스트 방을 만들고 [봇으로 끝까지 진행]을 눌러 5라운드가 끝나는지
- [ ] 라운드마다 점검표에 ❌가 없는지 (있으면 이유를 캡처해서 알려 주기)
- [ ] 엔딩 바로가기에서 4가지 시나리오를 열어 지구 엔딩 이름·그림 자리·이유 문구가 나오는지
- [ ] 시드를 바꿔 가며 지구 엔딩이 3가지 이상 나오는지, 법정에서 죄목이 나라마다 다르게 나오는지
- [ ] 법정에 "묻힌 경고" 횟수와 위험 조사 횟수, 적정 기술 투자액이 나오는지

## B. 학생 화면 (미리보기 + 실제 기기 1~2대)
- [ ] 1라운드: 카드 1, 2, 3, 5만 나오고 카드 4(더 할 일)는 건너뛰는지
- [ ] 2라운드부터: 카드 4에서 적정 기술과 위험 조사 타일이 나오는지, [건너뛰기]가 가장 큰지
- [ ] 3라운드부터: 도착한 피해가 있을 때만 피해 복구 타일이 나오는지
- [ ] 지난 라운드 선택이 미리 골라져 있는지, [이전]으로 돌아갈 수 있는지
- [ ] 최악의 예측 한 줄을 안 쓰면 [제출]이 안 열리는지
- [ ] 제출 후 마감 전에 [내 표 고치기]가 되는지, 마감 후엔 안 되는지
- [ ] 잠긴 단계(예: 모든 작물 LMO 이후)가 회색으로 막히는지
- [ ] 새로고침이나 탭을 닫았다가 다시 들어오면 내 자리로 복귀하는지
- [ ] 연결을 끊었을 때(와이파이 끄기) 연결 상태 표시가 바로 뜨는지

## C. 규칙 동작 (봇 + 실제 기기 섞어서)
- [ ] 같은 표 수가 나오면 한 번 재투표하고, 또 같으면 낮은 단계로 정해지는지
- [ ] 위험 조사 찬성이 과반이 아니면 실행되지 않고, 그 찬성표가 묻힌 경고로 기록되는지
- [ ] 위험 조사가 실행되면 해당 모둠에만 흐릿한 결과가 보이는지
- [ ] 추천만 눌린 상태에서 [선택권 풀어주기]를 눌러도 제출로 바뀌지 않는지
- [ ] [강제 마감]은 확인 창이 뜨고, 결과에 "강제 마감" 표시가 붙는지
- [ ] 결석 처리한 좌석이 투표 인원에서 빠지는지

## D. 보안·저장 (수업 전날 한 번)
- [ ] 학교 계정이 아닌 계정으로 교사 화면에 들어가면 막히는지
- [ ] 같은 출석번호를 다른 기기로 입장하면 막히고, 교사가 좌석 해제하면 들어가지는지
- [ ] Firebase 콘솔에서 라운드마다 백업 문서가 생기는지, CSV가 내려받아지는지
- [ ] 학교망에서 크롬북 2대로 동시에 접속해 화면이 서로 맞는지
- [ ] 이미지 없이도 자리 표시 그림으로 끝까지 진행되는지
